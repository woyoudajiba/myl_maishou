PREFERENCES

设置

管理视觉模型与浏览器插件连接。

视觉模型

已默认启用后台托管模型。模型密钥由服务器管理，不会下发到桌面端。

托管模型使用当前 TDL 登录身份记账。可添加自己的兼容模型；使用详情与账号用量见下方。

模型使用情况

每个账号仅能查看自己的记录；TDL 管理员可查看各账号汇总。

用量页需使用 TDL 账号登录，服务端按账号隔离统计请求数、成功/失败、Token 和响应时长，不保存提示词、图片或密钥。

平台账号

在平台登录页自动填写并提交已保存账号。验证码、滑块或安全验证仍需手动完成。

账号密码按当前 TDL 用户加密保存在这台电脑，重启及正常覆盖升级后继续保留。可随时修改；同一账号密码留空可保留原密码，更换账号需填写对应密码。

连接浏览器插件

首次在插件工作台填写下方长期配对码并连接一次；之后浏览器会保存配对信息并自动重连。退出桌面账号时本地服务暂停，重新登录后配对码继续有效。

GETTING STARTED

使用说明

连接插件和模型后导入选品表；自动处理正常商品，集中处理例外。

先了解两个工作界面

浏览器插件

复用你在各平台的登录状态，负责搜图、收集商品候选。

桌面工作台

保存任务、调用视觉模型、展示匹配分，供你逐条审核。

买手流程：导入商品 → 自动采集并整理资料 → 直接保存正式互拓待审核 → 在互拓中审核上架。

STEP 01

安装浏览器插件

内置插件版本

随客户端附带

  1. 点击“准备插件”，再点击“打开插件文件夹”，或复制上方目录。
  2. 在 Chrome 地址栏打开 chrome://extensions/，或在 Edge 打开 edge://extensions/。
  3. 开启“开发人员模式”，选择“加载解压缩的扩展”，选中上方文件夹。不要选择客户端安装目录或 ZIP 文件。
  4. 在浏览器工具栏的扩展菜单中固定“找商品”，点击图标打开插件工作台。

这个固定文件夹需要保留。以后客户端升级后，回到这里点击“更新插件文件”，再在浏览器的扩展卡片上点击重新加载，继续使用原来的配对信息。请勿重复加载多个版本。

02登录平台并连接桌面端
  1. 使用已有 TDL 账号登录桌面端。这个账号用于工作台，与批发平台的账号分别登录。
  2. 在同一个 Chrome / Edge 浏览器资料中，打开并登录网商园、17网、青创网、衣衫汇等你要使用的平台。验证码或权限提示需在平台页面手动处理。
  3. 进入桌面“设置”，复制本机地址和长期配对码；粘贴到插件工作台，点击连接桌面端。
  4. 确认插件显示“已连接”，并启用将结果交给桌面端比对。插件会保存配对信息；退出桌面账号时连接会暂停。
03添加并选择视觉模型
  1. 在“设置 → 视觉模型”点击添加模型，填写支持图片输入的模型 ID、API 地址和 API Key，支持 OpenAI 兼容服务。
  2. 保存后可以测试连接。测试会发送一次小图请求，可能产生服务商费用。
  3. 回到工作台选中要使用的模型。默认 3 批并发，可在模型配置中设为 1～4 批；服务较慢或容易超时时可调低。

API Key 使用 Windows 安全存储加密，按 TDL 账号分别保存。模型调用由所选服务商计费。

04单图 / 多图搜商品
  1. 从浏览器插件打开工作台，选择要搜索的平台。
  2. 单图点击“选图并搜索”。多图点击“批量添加图片”或拖入图片，每组最多 10 张；裤子、上衣等不同商品按图片分别保存条件、候选和审核结果。
  3. 可选填款号；已有成本时选择找低价商品模式并填写成本条件。
  4. 批量搜图按图片依次执行。切换图片可检查各自候选，平台失败时先查看简短原因并处理登录或验证。

搜图完成不会自动识别。先检查候选与图片清晰度，再确认提交模型。

05确认开始识别与失败重试
  1. 检查当前图的搜图结果后，点击确认识别；多图可以确认全部待识别图片，才会进入桌面任务队列。
  2. 桌面任务显示成功、失败和尚未识别数量。优先获取高清图片，每批最多 4 张候选，按模型并发设置执行。
  3. 模型失败后自动重试最多 3 次；仍未完成时点击“重试未识别候选”，开启新一轮识别并恢复 3 次自动重试额度。
  4. 重试沿用原任务，只提交未完成候选，保留成功结果和人工审核；连续点击不会重复建批次。已提交的失败请求是否计费由服务商决定。
06核对款式并确认同款
  1. 打开结果，点击“从最高相似开始审核”或候选的“人工核对”。
  2. 并排核对品类、廓形、领口、门襟、袖型、口袋、拼接和图案位置。颜色、光线和背景差异通常不影响同款判断。
  3. 直接选择确认同款并继续、排除候选或无法判断；无需重新评分。备注可选，确认同款后进入供应商资料采集。
  4. 最高模型分达到 90 时排除 85 分以下，达到 85 时排除 70 分以下，更低时沿用 50 分及以下排除。已排除项可查看和纠正；模型建议始终与人工确认分开显示。
07导出、删除记录与更新软件

每条桌面任务保留创建和更新时间，可导出完整结果、删除本批记录，或清空已结束记录；排队和识别中的任务不会被删除。记录按账号保存在本机，换电脑不会自动同步。

每次登录自动检查新版本，也可以到“软件更新”手动检查。确认后下载，完成后点击“重启并安装”；有排队或识别任务时需先等任务结束。

常见问题

只有商品链接的表格怎么开始？

先设置一次视觉模型和互拓连接，并在装有插件的浏览器登录平台。回到买手工作台，导入XLSX、CSV或TSV，确认后正常行自动开始处理，不需要上传图片。单条商品可直接用添加单个链接。每件商品显示分步流程进度；待处理区只保留需要你补充或选择的例外，资料完整后直接保存到正式互拓待审核，跳过草稿箱；最终审核上架仍需在互拓中手动完成。

如何批量用淘宝以图搜同款？

进入买手自动化，点击批量导入商品图片，每张图建立独立任务。勾选任务后批量淘宝搜款。候选返回后点击开始识别，到工作台核对匹配分并人工确认同款，再回到买手任务选择套图来源。

请在安装找商品插件的同一浏览器登录淘宝。搜索使用压缩副本，模型复核使用高清图片。登录失效或安全验证会暂停淘宝队列；在浏览器完成验证后继续队列，失败项可单独重试。没有可靠同款时保留未确认结果。

如何下载抖音商品主图？

在左侧进入“抖音主图”，粘贴商品分享文案或链接，选择保存位置和 PNG / JPEG，再点击开始下载。每个商品单独建立文件夹，停止后保留已完成图片；平台要求登录或验证时，当前隔离浏览器暂不支持登录，可尝试公开分享链接或稍后重试。

已经登录，为什么平台还是报错？

TDL 登录、各平台登录和浏览器资料互相独立。请确认插件所在的浏览器资料已登录相应平台，并检查账号是否具备搜图权限、是否遇到验证码或额度限制。平台连接检查只诊断，不会替你登录或搜索。

图片太小、细节看不清怎么办？

清晰度会影响识别。软件优先获取平台原图并记录来源与送模尺寸；质量不足会显示原因。人工审核使用本次实际送模图片。请先核对细节，必要时打开商品详情确认，不要只依赖分数。

客户端更新后，插件要怎么更新？

回到本页，点击“更新插件文件”，然后在浏览器扩展管理页对已有“找商品”点击重新加载，关闭旧插件工作台后重新打开。保持加载目录不变，不要重新安装另一个副本。
