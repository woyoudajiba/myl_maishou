# 自动买手当前实现与验收边界

默认目标已经由用户确定：资料完整的商品自动进入互拓待审核；异常打标签保留并继续下一件。入口是只有商品链接的运营选品表，不要求用户提供图片。

## 三类来源

- 淘宝或天猫链接：自动读取网页主图与套图来源，再搜索四个供应商平台。
- 抖音链接：自动打开已配对浏览器中的商品页面获取主图，再找供应商与可供互拓采集的淘宝同款套图。
- 网商园、17网、青创网、衣衫汇商品链接：自动读取当前商品资料与主图，继续查四个平台的同款供货与套图。

所有路径都必须取得供应商资料；营销套图不能替代供货成本、颜色尺码、成分和质检依据。

## 默认流水线

1. 导入 XLSX、CSV 或 TSV，预览链接类型和异常；原文件、工作表、行号与任务绑定。重复导入同一表跳过已有行，跨表相同来源保留重复标签。
2. 正常行自动打开来源网页并取得清晰商品图；没有表内图片也可以继续。单个商品链接走同一条流程。
3. 四个平台搜索；模型核对候选细节。自动采纳要求至少92分、疑似同款，并且没有差异与不确定项。50分及以下仍在识别记录中默认排除。
4. 多个可靠供应商同款先标记，继续下一件；人工只需在例外里选择一次供应商，之后自动继续。处理例外时，来源商品链接识别到的图片会作为图集展示；可按候选商品链接请求配对浏览器读取详情图集，并放大逐张查看。
5. 采集供应商主图库与供货文字；推荐商品区域不作为该商品图库。提取成本、货号、颜色、尺码和成分时保留连续引文，图片 OCR 事实须再次独立复核；值与引文不一致则拒绝采用。
6. 淘宝来源直接保留原套图；其他来源自动在淘宝找可靠同款。互拓采集按原 externalId 查询恢复，不因重试反复新增。
7. 从互拓读取启用类别、字典、颜色库、供应商档案与当前类别控件；模型只选真实枚举，程序校验颜色/尺码交集及对应数组。
8. 按业务文档将普通评分默认为0，供货周期采用可配置的业务默认12天。库存300不属于当前新增DTO，不伪造为真实库存，也不提交不存在的stockCount字段。
9. 完整草稿发送前固定正文与幂等键；回读草稿、使用真实draftVersion转换待审核，再回查正式productId/productNo与状态。
10. 回填CSV保留原文件、工作表、行号、链接、标签、原因和互拓编码。原运营表不被覆盖。

## 界面

登录默认进入买手工作台，主要操作是导入表格或添加单个链接。每条链接显示读取图片、寻找供应商、取得供货资料、核对套图、整理互拓资料、进入待审核六阶段，并显示当前具体步骤。可以筛选例外、队列或已完成项。

手动搜款、补录与高级连接设置折叠。默认渲染50条任务，按需继续显示；供应商例外支持选择并继续，缺供货资料支持补充后继续原任务。模型、互拓与插件连接状态在主入口可见。完整候选图集通过配对浏览器只读商品页读取；浏览器未登录或图集读取失败时显示状态，可重试，且不影响候选人工判断或自动任务。识别与复核中的供应商同款结果提供“人工确认是同款，继续下一步”，确认后自动回到买手任务并进入供应商资料采集；单独保存分数会保留审核记录但不会推进流程。

## 数据与恢复

- TDL用户之间的买手任务和互拓配置隔离；互拓账号密码与OAuth密钥使用Windows安全存储加密，快照和插件均不返回这些凭据。
- 浏览器只承担已授权页面采集与搜索；验证码、扫码和安全验证交给用户完成，不绕过平台验证。
- 重试从原检查点恢复，保留已取得资料。模型或互拓在途请求中断时标记回执未知，不自动当成功或换键新增。
- ERP字典与类别缓存5分钟，模型图片最多降到1600边，不放大缩略图冒充高清。浏览器搜索逐张调度，模型沿用已有批次并发。

## 在线选品表

- 工作区优先级为“商品录入与处理 → 识别与复核 → 抖音主图辅助下载”；自动处理进度和需要人工介入的例外留在商品录入页，识别与复核页用于查看模型证据。
- 共享行由另一台电脑处理到供应商搜索/比对异常时，可从本机按原商品链接重新开始；服务端确认行版本和旧任务编号后改绑。供货采集或互拓提交阶段不会跨设备接管。
- 在线选品表托管于找商品自有云端服务；TDL 登录后自动发现、复用共享表，不要求用户填写服务器地址或表格访问令牌。只有 TDL 管理员可创建共享表，普通账号按 TDL 会话读取和编辑。
- 表格行支持货号、来源类型、HTTPS 商品链接、标题、备注、人工状态和互拓回执。多人可以同时编辑；同一行保存使用 `ifVersion`，冲突返回409并要求刷新。
- 只有人工确认（`approved`）的行可以被桌面端领取；领取采用服务端原子条件更新，避免两台客户端重复创建买手任务。互拓仍遵循现有草稿/待审核门禁。
- 表格服务使用 SQLite WAL、行级版本号和索引，客户端按页读取；本地 XLSX 可导入共享表，在线表格可分页导出 XLSX。服务实现、API、备份和生产反向代理说明见 `table-server/README.md`；服务数据目录不能放入源码或日志。

## 已验证与仍需真实验收

已通过三类链接/单元格超链接/WPS图片解析、重复导入、异常继续、供应商证据校验、互拓幂等恢复、Electron自动流水线、单链接重复输入、小窗口与旧功能回归。Electron全链路使用受控网页、模型和互拓写入响应，不能等同真实业务商品验收。

真实互拓只读联调读取了27个启用类别和921项字典，并确认实际动态控件结构及套图来源枚举。尚未通过本流水线创建真实商品、执行真实转换或发布云端更新。

四站真实资料完整性、抖音/淘宝当前登录页采集、连续批量搜图和真实大模型质量仍需业务链接验收。现有互拓接口未接通全库图片查重及既有商品追加套图；已有商品和待补证明保留为例外，不能声称已覆盖或已自动处理。
