# 在线选品表任务确认人

用户要求将在线选品表主表中的“备注”列替换为确认任务的用户，例如“吴少凡”。

## 实现

- 主表列名改为“任务确认人”，以只读文本显示实际确认用户的姓名；悬停可查看确认时间。
- 点击确认时，由在线表服务从 TDL 认证结果获取用户 ID、显示名称和当前时间，保存为 `confirmedUserId`、`confirmedBy`、`confirmedAt`。不接受客户端输入的姓名作为确认身份。
- 最后修改人仍用于原有审计记录，确认人独立保存，后续标题编辑、自动流程回写、任务领取或跨电脑继续处理不能覆盖。
- 未确认或已驳回的行显示“—”；取消确认时清除当前确认归属，再次确认由当次认证用户重新记录。
- 原备注仍保存在原字段，可通过“更多字段”查看和编辑；导入和原有备注导出保留。主表批量粘贴范围相应为货号、商品链接、标题三列，姓名不可粘贴修改。
- 整表查找支持按确认人姓名查找，修改历史可显示确认人和时间变化。

## 旧数据

在线表 SQLite 增加三个字段，以事务执行迁移和历史补回。仅从当前商品的真实确认/已确认导入历史中取得确认人，不把最后编辑人或当前登录人推测为确认人。找不到依据的已确认行显示“历史未记录”。

回档时保留已领取任务的确认归属，未领取行沿用原有恢复为待确认的规则，同时清空当前确认字段，避免回档导致未经确认就继续任务。
