# 识别结果驾驶舱与自动重试验收

## 实现结果

- 识别批次首屏显示待人工核对、需重试、已排除、确认同款；总候选数降为次要信息。
- 主动作依次为审核、重试、查看平台问题、导出。确认供应商同款后进入资料采集；淘宝同款保留选作套图来源的流程。
- 默认筛选为推荐先看，优先疑似同款，再到相似款、无法判断，同类按分数排序；默认先显示 8 条。支持平台、状态筛选及查看全部候选。
- 显示网商园、17 网、青创网、衣衫汇及淘宝来源；保留准确搜/相似搜元数据。没有已知检索类型的历史记录只显示图片搜款，不推断准确/相似类型。
- 模型建议与人工确认分开显示。审核提供确认同款并继续、排除候选、无法判断三个动作，无需重填分数。原有手工分类和参考分调整保留在折叠的可选补充审核中。
- 模型协议与审核提示优先比较款式和结构。颜色、光线、背景差异本身不构成否定同款依据；同时出现明显面料、图案、结构或工艺变化时才作为重要差异。

## 动态排除规则

| 整批最高模型分 | 自动排除 |
| --- | --- |
| 至少 90 | 85 分以下；85 分本身保留 |
| 85～89 | 70 分以下；70 分本身保留 |
| 低于 85 或尚无可评分结果 | 沿用 50 分及以下规则 |

排除只改变视图和筛选，不删除候选、证据或导出记录。门槛按完整批次计算，切换平台不会改变门槛；新增成功识别会重新计算。人工直接确认可纠正低分候选。历史人工参考分调整继续保留并可用于排序和筛选。

## 自动重试

桌面端首次识别后仍有未完成项时，最多自动重试 3 轮。重试只提交未完成候选；已成功结果、原始索引、任务编号、创建时间及有效人工记录保留。后续轮次继续处理其他未完成候选，避免单个失败项阻断整轮。

3 次自动重试耗尽后停止，等待人工点击“重试未识别候选”。该点击启动一次识别，并重置额度，使后续仍可自动重试 3 次；可再次按相同方式续轮。计数落盘保存，重复点击合并，不新增识别任务。退出登录停止执行；原有应用异常退出时对未知在途回执的保护保留。浏览器扩展独立模型执行仍使用原有暂停流程；自动续轮由桌面队列负责。

## 主要文件

- `desktop/renderer.js`、`desktop/style.css`、`desktop/index.html`：驾驶舱、筛选、来源、状态和说明。
- `review.js`、`review-ui.js`、`review.css`、`core.js`：共享审核、排序与动态排除。
- `desktop/bridge-server.js`、`desktop/comparison.js`：原批次重试、计数持久化与来源字段。
- `desktop/buyer-providers.js`、`desktop/buyer-renderer.js`、`workbench.js`、`workbench.html`：来源与平台问题传递、下游候选口径。
- `vision-protocol.js`：颜色辅助、款式与结构优先的模型规则。
