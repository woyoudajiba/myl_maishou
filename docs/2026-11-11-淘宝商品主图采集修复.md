# 淘宝商品主图采集修复

## 现象与原因

用户已更新浏览器插件，且自动买手日志显示页面打开、浏览器命令已接单，但任务因“未识别到商品主图”停在来源采集阶段。当前淘宝商品采集只从 JSON-LD 和 `og:image` 读取图片，没有检查页面上渲染的商品轮播。因此，页面能显示商品主图，采集结果仍可能为空。

## 修复

- 增加淘宝 / 天猫商品图区域和可见大图 DOM 读取；支持当前图、放大图、大图、延迟加载与 `srcset` 地址。
- 仅接受许可的淘宝图片 CDN 和商品图片路径；跳过缩略图尺寸、店铺/推荐/评价区图片和站外资源。
- 轮播主图排在通用元数据图之前，供来源商品首图下载优先使用。
- 新增回归样本，模拟无 JSON-LD / `og:image`、可见主图轮播、缩略图、店铺 Logo 和推荐图。

## 验证与边界

- `node --test browser-test/buyer-page.test.js test/buyer-page-wait.test.js`：6 项通过。
- `npm.cmd test` 全量通过情况见本次验收结果；本轮没有直接访问或自动化操作用户的 Edge 页面。
- 该修复已随 `26.11.10-v3` 打包发布。v2 不包含淘宝轮播读取规则；需安装 v3，并在“使用说明”准备 v3 插件后到 Edge/Chrome 扩展管理页重新加载。
