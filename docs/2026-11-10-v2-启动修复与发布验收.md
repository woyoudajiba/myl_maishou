# 26.11.10-v2 启动修复与发布验收

修复 v1 安装后主进程报 `Cannot find module './model-retry'` 无法启动的问题。根因是新增的 `desktop/model-retry.js` 未包含在打包脚本的显式文件复制清单，源码测试和浏览器插件校验均不能发现这个成品缺陷。v1 的更新清单和下载首页现已被 v2 替代；原版本文件不覆盖。

## 修复与预防

- `scripts/package-release.js` 增加 `model-retry.js`，在构建前检查暂存目录、构建后检查 app.asar 的本地 require/import 依赖。
- `scripts/check-package-dependencies.js` 已对原 v1 成品复现并拦截 `desktop/buyer-providers.js -> ./model-retry`；回归测试覆盖间接缺失模块和 ERP 动态导入。
- 构建交付前自动执行 `scripts/check-packaged-startup.js`，使用临时独立资料目录启动实际 `ProductComparison.exe`，确认登录按钮可见、版本正确及两个相关模块可被主进程加载。
- 发布前要求启动验收记录与实际安装器、插件和更新元数据哈希一致，阻止遗漏运行验证的包直接发布。
