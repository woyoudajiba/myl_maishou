# 买手子页面、网页版选品表与平台账号保留

## 本轮需求

用户希望将“在线选品表”和“商品进度与待处理例外”改为顶部切换子页面，减少长页面滚动；同时在 maishou 网站提供独立选品表，客户端表格区域精简。上一条需求要求平台账号本机保存、正常升级后保留并支持修改。

## 客户端

- 顶部新增“选品表 / 商品进度 / 导入商品”三个子页，可鼠标和键盘切换，不再将三个区域上下堆叠。
- 新任务导入或添加链接后跳转商品进度；从商品流程返回原表行会打开选品表子页并定位原行。子页切换保留未保存输入，沿用原表格版本校验和任务关联。
- 导入、单链接、暂停/继续、结果导出和当前队列摘要放在公共操作区；错误与操作反馈也保留在公共区域。
- 客户端表格视口上限缩为330像素；查找、定位、历史和导出等低频工具放入可展开工具区，保留原有本地表格编辑能力。
- 增加固定的“在网页打开完整选品表”按钮，仅打开 `https://wsfile.cn/maishou/table/`，不在网址中携带登录凭据。

## 网页版

- 静态文件：`maishou-service/site/maishou/table/`。发布后的访问路径为 `/maishou/table/`，maishou 账号页面增加入口。
- 使用现有 TDL 登录、会话存储方式与同源在线表接口，和桌面端共用一张选品表，不另建业务数据。
- 支持新增、粘贴批量导入、编辑、按确认人等字段查找、分页、人工确认、删除、修改记录、管理员预览后回档及 CSV 导出。
- 确认人由服务端认证身份记录。网页不领取本地任务、不读取平台账号、不直接写入互拓商品；确认后由运行中的桌面端按原队列领取，网页每30秒更新共享进度。
- 已领取行的来源与目录编号保持只读；编辑冲突保留用户输入，需刷新后重新核对。
- 配套 Nginx 精确入口与静态路由写入 `maishou-service/deploy/maishou-location.conf`。部署时需发布静态资源、更新在线表服务，并执行 `nginx -t` 后再 reload。

## 平台账号

- 核实原有存储已位于 Electron 用户数据目录下的 TDL 专属 profile，账号文件整体使用 Windows 安全存储加密，不随安装目录或版本号变化。
- 沿用原加密文件格式与 TDL 隔离，不迁移或清空既有账号。正常重启、覆盖升级后保留；不同电脑或不同 TDL 账号各自管理自己的平台账号。
- 设置页明确显示“更新后保留”，已保存项显示“修改”。同账号密码留空保留原值，修改用户名必须输入对应密码。
- 安装配置显式设置 `deleteAppDataOnUninstall: false`，正常升级不清理本机资料。没有执行真实用户电脑上的卸载或覆盖安装。
- 使用旧 v1 成品在隔离用户目录保存平台账号，再从新版源代码入口读取、修改和重启，验证文件兼容与持久化；文件及快照均不含明文密码。
