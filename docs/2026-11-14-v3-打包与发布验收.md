按用户要求将 `26.11.14-v2` 递增至 `26.11.14-v3`，完成 Windows 安装器、便携版、Bundle 和浏览器插件打包，并上传更新站。桌面更新内部版本为 `26.11.14-3`，插件及 Windows buildVersion 为 `26.11.14.3`。

## 本版变更

- 识图工作台与买手自动处理支持 Top 和详细两个搜索档位。Top 每个平台最多保留前25个候选，四个平台最多100个候选进入识别；详细模式保留平台返回的全部候选。
- 平台连接检查包含网商园、17网、青创网、衣衫汇和淘宝五个平台；淘宝只做连接诊断，不加入四个平台的商品搜索。
- 草稿详情增加删除入口，删除前重新读取并确认 ERP 状态是 `DRAFT`；非 DRAFT 草稿不可删除。正式 ERP 若未部署删除接口，软件显示未提供接口且不会误报删除成功。
- 买手流程“继续原任务/重试未完成项”会刷新当前商品详情而保持弹窗打开。保存供货资料失败时标红对应字段并保留窗口与输入。
- 生产互拓代理源码默认固定正式 API 地址 `http://8.148.144.131/prod-api/admin-api`；只有显式测试模式允许测试端点。该代理源码本轮未部署到云端。
- 网商园搜索候选保留接口返回的发货地；详情采集读取页面中明确显示的发货地，并展示在识图结果与商品详情。
- 修复网商园材质 `title` 完整值读取和淘宝图搜令牌缺失/过期误报未登录；令牌错误时至多刷新并重新签名一次。
