# 任务与在线表格关联修复

本轮按“表格行与任务一一对应”修复源码。未打包、未发布、未部署在线表服务，也没有操作真实账号的任务或表格数据。

## 原因

- 在线任务原先只有 `onlineTableRowId`，没有持久化所属云表 ID；同步共用当前选中的表格客户端，切表后可能访问错误的表。
- 继续任务使用本机持久化链接和检查点，没有先核对当前表行的任务 ID、链接及是否已被删除。
- 任务列表直接展示所有本机历史任务，云表删除或重新导入不会同步清除旧任务；卡片没有删除入口，也没有表行与任务 ID 的直观对应。

## 当前行为

- 新任务保存 `onlineTableId`、`onlineTableRowId`、任务 ID 和来源链接；同步使用独立的原表客户端，不随当前界面选表改变。
- 继续任务、每个自动步骤与回写前核验原表行、任务 ID 和规范化链接。旧行不存在、换链接或已被接管则拒绝继续。旧任务只有完整匹配才补齐表 ID；切表后可按原行 UUID、任务 ID 和来源链接发现原表。
- 回写请求携带任务 ID，服务端在版本门禁之外核对绑定；旧任务即使拿到新版本也不能覆盖其他任务的回执。
- 默认任务范围为“当前表格与本地录入”；“全部历史任务”可查看其他表及已删除行的历史任务。服务返回当前有效行的任务 ID 清单，任务范围不依赖当前页或行号。
- 表格处理状态和卡片显示任务 ID；卡片“定位原表行”会核验后切回原表定位。存在未保存表格输入时阻止切表和定位。
- 表格导出及本地回填导出新增“任务ID / 在线表ID / 在线行ID”，不改变原有业务目录编号“表格ID”。
- “删除本机任务”有确认弹窗。允许删除待处理、完成、停止和未启动任务；阻止执行中或结果未知的请求。删除本机任务和自有主图，终止关联浏览器命令。保留云表任务 ID、互拓回执、独立识别记录与商品资料文件夹，避免自动重复提交。当前仍有效的未完成云表行回写为“已停止”；已删除或被接管的原行不被覆盖。新商品需新增表格行再确认。
- 打包文件清单已加入 `desktop/online-task-binding.js`，但本轮没有生成或验证新安装器。

执行环境：PowerShell 7.6.9、项目现有 Node 与 Electron；在线表使用临时 SQLite 服务和模拟 TDL 登录。模型及互拓请求禁止访问真实服务。

- `npm.cmd run test:table-server`：15 项通过。新增当前任务 ID 门禁和已删除行排除测试；保留版本冲突、接管、回档与回执保护。
- 本轮相关 Electron 场景 4 项通过：`desktop-buyer.test.js`、`desktop-online-table.test.js`、`online-table-cross-device-restart.test.js`、`online-task-binding.test.js`。

- 人工查看 1160 宽桌面及 800 宽窄窗口截图：新增按钮和任务 ID 可见，窄窗口阶段轨迹换行正常。

## 独立发现与边界

- 工作区“价格参考”改动一度重复声明 `priceGroups` / `priceComparison`，阻断整个桌面脚本及登录；仅去掉重复声明，保留现有功能。
- 扩大执行 `browser-test/desktop-review.test.js` 时，价格参考按钮顺序实际为青创网、网商园，断言要求网商园、青创网；该独立排序断言未通过，不能据此宣称全部浏览器测试通过。本轮未修改这项价格排序测试。
- 本轮为源码及本地接口验收。安装版需重建更新，云表服务需同步部署后才能完整启用有效任务清单及服务端任务 ID 门禁；真实账号、付费模型和生产互拓验收未执行。
- 原工作区的淘宝采集、供应商资料、价格参考、发布脚本等其他改动继续保留；本轮未提交 Git 或修改版本号。
