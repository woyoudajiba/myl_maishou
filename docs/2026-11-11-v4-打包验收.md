# 26.11.10-v4 本地打包验收

按用户“打包更新一下，版本号加一”将当前 `26.11.10-v3` 递增为 `26.11.10-v4`，先生成本地交付文件；随后按追加指令“需要上传一下”发布安装包、插件与更新清单。未部署在线表服务、未执行安装器覆盖用户已有安装。

## 本版内容

- 识别结果增加高相似候选价格参考：同批匹配分至少90，模型建议为同款或相似款且具有有效价格、商品链接的候选按价格升序排列；各自显示平台、货号、店铺和独立商品链接，货号不同也可比较。
- 供应商资料优先采用当前选中页面已采集的货号、店铺、明确单一供货价、颜色和尺码；页面字段覆盖模型漏填或误填，保留来源证据和阶梯价保护。
- 人工补资料表单显示选中平台、商品标题、页面报价与当前商品链接；详情图片在图集中分散取样，增加后续尺码表被识别的机会。
- 包含工作区已有的任务与在线表绑定、历史任务范围、失效任务保护及定位原行修复；`online-task-binding.js` 已装入成品。有效任务清单与服务端任务 ID 门禁仍需单独部署在线表服务。
