# 软件更新

云端文件目录固定为 `/home/wsf/productC`。公共入口 `https://wsfile.cn/productC/` 提供首次安装包和插件；桌面更新源为 `https://wsfile.cn/productC/updates/latest.yml`，由 Nginx 只读提供，不运行额外服务，也不接收账号和模型配置。

“软件更新”入口紧跟“设置”，登录后自动检查一次。发现新版时显示公告式提醒，用户可以忽略此次提醒，也可以立即下载；忽略不影响之后手动检查，下次登录会重新检查。用户点击才下载，SHA-512 校验通过后显示“重启并安装”，有排队或识别中的任务时阻止安装。关闭软件不自动安装。旧版本 v9 及之前不包含更新器，需要先手动安装 v10 一次。

当前已发布界面版本 `26.11.16-v2`；内部更新版本 `26.11.16-2`，扩展与Windows buildVersion为 `26.11.16.2`。资料完整后跳过草稿直接保存正式互拓待审核；真实店名与档口位置分离，完整供应商目录匹配与模型统一填表。云端已固定正式互拓地址并启用直接保存能力，两个账号只读检查通过。客户端与配套插件已打包上传，公网全量哈希及断点下载验证通过。详见 [26.11.16-v2打包与部署验收](2026-11-16-v2-打包与部署验收.md)。

## 发布新版

26.11.14-v2 新增软件内互拓草稿箱，支持按货号和供应商筛选、分页、查看价格成分颜色尺码动态属性及放大商品图片。自动买手停在草稿人工检查阶段，旧转换任务先回读；手动转换校验用户查看的草稿版本及权限，禁止并发转换，异常保留原草稿。切换或退出账号清空草稿界面和迟到响应。打包清单补入草稿箱显示和数据模块，并以实际成品启动验证其加载。详见[26.11.14-v2发布验收](2026-11-14-v2-打包与发布验收.md)。

26.11.14-v3 增加 Top 搜索（每个平台前25个，最多100个）和保留全部候选的详细搜索；连接检查扩展到四个平台加淘宝。买手详情重试保持窗口打开，资料校验错误标红；草稿删除仅允许 DRAFT 并在接口不可用时明确失败。识图结果展示网商园发货地；生产互拓正式地址固定逻辑已加入服务端源码。本轮打包、上传客户端和插件并完成公网校验，未部署云端服务端。详见[26.11.14-v3发布验收](2026-11-14-v3-打包与发布验收.md)。

1. 递增 `manifest.json` 的 `version_name`/`version` 和 `desktop/package.json` 的 `build.buildVersion`；更新 `build.releaseInfo` 的 `releaseName`/`releaseNotes`。
2. 在仓库根目录运行单元与桌面回归，通过后运行 `node scripts/package-release.js`，可用 `PC_RELEASE_DEST` 指向桌面子目录。脚本检查暂存目录和 app.asar 的本地依赖，实际启动打包后的 EXE 到登录页并记录启动证据；任一失败即停止交付。
3. 打包脚本自动将配套插件 ZIP 同时放入桌面交付目录与 `desktop/release`，并将同一份插件源装入客户端 `resources/browser-extension`。
4. 显式运行 `node scripts/publish-update.js`。脚本要求 `desktop/release/verified-<显示版本>.json` 与当前产物哈希及启动结果一致。使用 `PC_DEPLOY_KEY` 指向授权 SSH 私钥，默认使用当前机器的部署身份路径。私钥内容不进入项目或云端目录。
5. 脚本验证 installer 的 SHA-512 与 `latest.yml` 一致，再上传安装包、blockmap、插件和校验清单至私有暂存目录，远端复核 SHA-256。安装包按版本不可覆盖，先发布文件，最后原子替换 `latest.yml`。
6. 核对 HTTPS 元数据、安装包大小与 Range 响应、全量下载校验，以及已安装客户端的“检查更新”结果。不得临时提高生产版本来制造测试更新；使用隔离客户端和受控测试响应。

首次配置：上传 `deploy/configure-updates.py` 和 `deploy/productC-location.conf` 到同一私有暂存目录，用 sudo 执行配置脚本。只创建 `/home/wsf/productC` 和在现有 TLS server block 加一个独立 include，Nginx 校验通过才 reload；失败恢复原配置。备份配置不在公开的 updates 目录。

## 边界

使用 electron-updater 6.8.11 + NSIS，关闭自动下载和退出即安装；下载失败不影响商品任务，可手动重试。抖音商品工作流通过配对本机 API 写入限量、原子持久化的浏览器命令队列；每张抖音主图下载完成后自动排入首图搜四个平台任务，扩展用既有浏览器资料搜索，且只搜索该图片。只有任务候选保存了与当前图片/模型响应绑定的人工 `likely_same` 结论，详情命令才可创建和提交结果。详情字段及图库 URL 随候选本地保存并进入完整 JSON 导出。桌面应用不自动替换浏览器加载的解压插件，插件更新仍需浏览器扩展管理页处理。

更新安装器会按旧安装路径先关闭对应桌面进程，失败时保留旧文件并写入 `%LOCALAPPDATA%\ProductComparison\installer-logs\upgrade.log`，不会删除商品资料或账号数据。当前无可信 Authenticode 证书，安装包为未签名版本；通过 HTTPS 和 SHA-512 校验传输完整性，不把摘要校验称为发行者签名。获得证书后应启用签名及发布者验证。

参考：[electron-builder 自动更新](https://www.electron.build/docs/features/auto-update/)。实际行为以锁定的 6.8.11 源码和回归测试为准。

从 v11 开始，客户端内置同版本插件，“使用说明”提供准备/更新插件文件和打开固定目录的入口。升级客户端后须由用户在说明页更新插件文件并在浏览器重新加载，保持加载目录不变；客户端不绕过浏览器的扩展安装确认。
