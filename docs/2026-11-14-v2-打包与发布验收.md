# 找商品 26.11.14-v2 打包与发布验收

按用户“打包更新上传，版本号加一”的要求，将 `26.11.14-v1` 升级为 `26.11.14-v2` 并发布。桌面更新版本为 `26.11.14-2`，扩展及 Windows buildVersion 为 `26.11.14.2`。

## 本版变更

- 软件左侧新增互拓草稿箱，支持按货号、供应商筛选、分页和刷新。
- 显示供货价、成分、颜色、尺码、动态属性及套图、公版图、详情图，支持图片放大和加载失败占位。
- 自动买手完成资料整理后保存草稿，停在 `draft_review` 等待人工检查；人工确认后才转入互拓待审核，最终上架仍由人工在互拓中完成。
- 旧任务的自动转换步骤先回读草稿，不直接调用转换。手动转换按用户已查看的草稿版本校验，防止重复点击并发转换；未知状态或读取失败不会当作可转换草稿。
- 切换或退出账号时清空草稿界面，忽略旧账号的迟到响应。
- 打包清单补入 `buyer-draft-view.js` 与 `buyer-drafts-renderer.js`；成品启动和发布门禁显式检查两个草稿箱模块已加载。
