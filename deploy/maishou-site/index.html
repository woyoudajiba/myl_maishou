展开安装细节：插件该加载哪个文件夹？
  1. 推荐在桌面端“使用说明”点击“准备插件”，再点“打开插件文件夹”。客户端已内置配套插件，无需再下载 ZIP。
  2. 如果使用本页插件 ZIP，先完整解压到固定位置，例如 D:\找商品插件。选择的文件夹内应直接包含 manifest.json。
  3. Chrome 地址栏输入 chrome://extensions/；Edge 地址栏输入 edge://extensions/，按回车打开。开启“开发人员模式”，点击“加载解压缩的扩展”。
  4. 选中第 1 步或第 2 步的插件文件夹，固定到浏览器工具栏，再点击插件图标打开工作台。不要选择 ZIP 文件，也不要重复加载两个版本。
  5. 保留这个目录。升级客户端后，在“使用说明”更新插件文件，再回浏览器对已有插件点击“重新加载”。
首次配对：软件和浏览器怎样连接？
  1. 桌面端保持 TDL 登录，进入“设置 → 连接浏览器插件”，复制本机地址和长期配对码。
  2. 打开浏览器插件工作台，启用“交给 Electron 比对”，填入对应地址和配对码并连接。
  3. 看到桌面端或插件显示已连接，再在同一个浏览器资料中登录网商园、17网、青创网、衣衫汇；需要淘宝套图时也登录淘宝。
  4. TDL 登录和平台登录相互独立。验证码、扫码或滑块需要自己完成。换浏览器或清除插件数据后需要重新配对。
开始自动买手前，互拓需要配置什么？
  1. 进入“设置 → 自动买手与互拓连接”，这里只显示连接状态，无需填写任何连接参数。打开“互拓账号页面”，登录 TDL 后只填写自己的互拓账号和密码。
  2. 在云端账号页面保存账号，点击“检查连接”验证登录、权限、字典和类别。密码和 OAuth 密钥加密保存在服务器，客户端不保存或接收这些密钥。换电脑登录同一 TDL 账号即可复用。
  3. 确认自动完成位置是“互拓待审核”还是“仅保存互拓草稿”。待审核不代表已经完成店铺发布。
  4. 保持桌面端、插件和所需平台登录正常。第一次建议用少量真实商品核对同款、成本、规格和互拓回执，再增加批量。
导入后怎么看进度、处理例外和导出结果？
  1. 本地表格每行一个完整商品链接，在导入预览中检查链接类型和异常后确认导入；共享选品表需要逐行点击“确认并提交”。
  2. 回到“商品录入与处理”查看阶段进度。正常项按配置保存草稿或进入待审核；可以随时暂停新步骤。
  3. 筛选“待集中处理”，点击“处理例外”。多供应商候选可选择供应商继续；已采集供应商详情的任务可补充已核实供货资料。已有商品、特殊证明等缺少完整处理入口时需回互拓或联系管理员处理。
  4. 在“识别与复核”核对模型的吻合点、差异及图片。已完成项显示互拓编码，可“导出回填结果”；共享表会同步状态与编码，本地原工作簿需用导出文件核对回填。

04 · OPERATING GUIDE

你只需要确认三类事情

软件会把可以由程序和模型完成的工作先跑完，把需要业务判断的内容单独列出来。

01同款是否可靠模型展示吻合点、差异和待核实内容；有不确定项时不会自动当成同款。
02供应商资料是否真实成本、货号、颜色、尺码和成分必须有页面或图片依据，模型不会猜填。
03特殊业务是否确认库存、质检报告、洗水唛、专版授权和价格差异仍按实际业务证据确认。

05 · FAQ

常见问题

插件加载后没有反应怎么办？

确认插件已经在当前浏览器重新加载，桌面端处于登录状态，并且插件里填写了桌面端“设置”中显示的本机地址和配对码。供应商平台需要在同一个浏览器资料中登录。

软件会自动发布到电商店铺吗？

当前流程自动推进到互拓草稿或互拓待审核，并回读商品编码。它不会绕过平台验证，也不会代替店铺最终发布动作。

为什么有些商品会停在待处理？

常见原因是多个可靠供应商、同款证据不足、供应商资料缺失、货号冲突、同一商品已存在或平台需要登录验证。打开商品详情即可看到原因和可用操作。

客户端升级后插件需要重新安装吗？

进入桌面端“使用说明”，点击“更新插件文件”，然后回到 Chrome 或 Edge 扩展管理页对原来的插件点击“重新加载”。保持插件目录不变可以保留配对信息。

在线选品表误删或改错怎么办？

在“商品录入与处理 → 在线选品表”点击“修改记录”，可以查看操作人、时间和字段前后内容。管理员选择“恢复操作前内容”后先看影响范围，再确认回档；回档不会撤销已创建的互拓商品，已领取任务和互拓编码会保留。

安装包为什么会有 Windows 提示？

当前安装包没有 Authenticode 证书签名。请确认文件来自本页下载地址；如果公司设备策略阻止安装，请联系管理员。后续更新由桌面端校验后再安装。

在线表怎样连续填写和查找商品？

进入“商品录入与处理 → 在线选品表”，直接在空白行填写，填到末尾会继续增加空白行。所有字段均可留空，商品数量只统计链接列不为空的行；链接是否有效在确认提交时检查。支持粘贴 Excel 多行多列，填写后点击“保存未保存行”。使用“查找整张表”和“上一处 / 下一处”可跨页定位并高亮匹配行，也可以输入行号直接跳转。

固定字段测试表在哪里？

安装并登录 26.11.08-v1 客户端后，进入“商品录入与处理”，点击“下载测试表模板”。模板包含选品日期、表格 ID、平台链接、商品编码和互拓编码等字段；设置中还可以选择买手资料根目录。
